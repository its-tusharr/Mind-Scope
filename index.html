About This Project

MindScope is a machine learning portfolio project. A regression model, trained on a survey-style dataset of student social media usage and wellbeing, estimates a mental health score from the habits you enter. The frontend is plain HTML, CSS and JavaScript and talks to a FastAPI backend that serves the model.

Disclaimer. This tool is intended for educational and informational purposes only. Its output is a machine-learning prediction, not a clinical assessment, diagnosis, or substitute for advice from a qualified mental health professional. Model predictions may be inaccurate and should not be used to make medical decisions.
